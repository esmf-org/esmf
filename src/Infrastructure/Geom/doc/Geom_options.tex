\subsubsection{ESMF\_GEOMMATCH}
\label{const:geommatch}

{\sf DESCRIPTION:\\}
 This type is used to indicate the level to which two ESMF\_Geom objects match.

The type of this flag is:

{\tt type(ESMF\_GeomMatch\_Flag)}

The valid values are:
\begin{description}
\item [ESMF\_GEOMMATCH\_INVALID:] Indicates a non-valid matching level. Returned
      if an error occurs in the matching function. If a higher matching level
      is returned then no error occurred.
\item [ESMF\_GEOMMATCH\_NONE:] The lowest level of matching. 
      This indicates that the Geom's don't match at any of the higher levels. 
\item [ESMF\_GEOMMATCH\_ALIAS:] Both Geom arguments are aliases to the exact
      same Geom object in memory.
\item [ESMF\_GEOMMATCH\_GEOMALIAS:] The Geom objects are distinct. However, the underlying geometry
      objects (e.g. Grids) are aliases of each other. 
\end{description}
